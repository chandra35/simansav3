# Dokumentasi SIMANSA

## Wajib Dibaca Untuk UI

Sebelum mengedit tampilan menu/fitur lama atau membuat fitur baru, baca:

- `docs/UI_DESIGN_PRINCIPLES.md`
- `docs/UI_BUTTON_STYLE_GUIDE.md`

Prinsip utama: AdminLTE default menjadi fondasi. Custom CSS hanya dipakai untuk memperhalus tampilan dan harus scoped per modul agar tidak merusak fitur lain.
